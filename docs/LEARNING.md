# LEARNING.md — component → research concept → incident map

The evidence index for the build narrative. One row per system component:
what it is **in this repo**, the research concept it implements, the
incident or measurement that stress-tested it, and the lesson. Every cell
sources from BUILD_JOURNAL.md, `evals/results/`, or a PR — no embellishment.
Where a number's comparability has a caveat, the caveat is stated; the map's
value is its honesty.
